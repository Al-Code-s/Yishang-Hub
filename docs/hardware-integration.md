## 二、数据模型（阶段 5）

```text
连接配置 → 网关/设备 → 测点 → 原始消息 → 标准化读数 → 汇总/告警
```

| 实体 | 关键字段 |
| --- | --- |
| 连接配置 | 协议、地址、凭证引用、超时、启用状态 |
| 网关/设备 | 设备编码、类型、位置（工厂/车间/线体）、状态 |
| 测点 | 设备、测点编码、物理量类型、单位、量程、精度、是否累计值 |
| 原始消息 | 原始报文、接收时间、来源 IP、消息 ID、处理状态 |
| 标准化读数 | 设备时间、接收时间、数值、单位、数据质量、来源、去重依据 |

读数与消息的必带字段见 `docs/energy-calculation.md` 第一节。

## 三、首版必须实现（任务书 11.3）

1. **独立可配置模拟器**（作为可选开发服务，**必须显著标识为模拟**）。
2. **HTTP 采集入口**。
3. **设备独立凭证**（不复用员工登录会话）。
4. **请求限流与批次大小限制**。
5. **重复数据处理**（去重依据：消息 ID / 设备+测点+设备时间）。
6. **读数展示与历史查询**。
7. **离线告警**。
8. **越限告警**。
9. **模拟标识**。
10. **采集失败日志**。

**MQTT、Modbus 等保留适配设计**，按真实设备情况开发，**不预先宣称已完成**。

## 四、网络边界（任务书 11.5）

- **默认只读采集**。
- 不把数据库或工控设备直接开放到互联网。
- 采集网络与办公访问应按实际网络条件隔离。
- 远程访问使用受控通道。
- **不在平台中下发安全逻辑修改**——平台不替代 PLC 实时控制、安全联锁、SIS 或消防联动。

## 五、工业终端安全（任务书 10.14，阶段 6）

必须**明确区分**三种数据来源，界面与报表上都可辨识：

```text
人工登记    —— 由人员手工录入的状态
代理采集    —— 由终端代理上报的状态
文件导入    —— 从扫描报告等文件导入
```

**不得将人工录入包装成自动检测。**

- 主机资产、系统版本、防病毒软件状态、特征库更新时间、补丁台账、配置检查、
  风险整改、扫描报告附件、巡检与提醒。
- **补丁与重启操作需审批与维护窗口**（不自动执行）。
- **不自研杀毒引擎**（任务书 2.3.2）。
